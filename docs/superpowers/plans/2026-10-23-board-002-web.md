# BOARD-002 Board on the Web Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The friends-only Board on the web: Friends opens on Board (composer + friends' posts, Recent/Top), Lately becomes its second view, a post page holds the thread, and a title page shows "From friends".

**Architecture:** A pure `lib/board/model.ts` (tested) for display logic, `lib/board/server.ts` server functions over the generated `/v1/board*` client (same pattern as `lib/groups/server.ts`), and `components/board/*` built from `src/components/ui` primitives and Aaru tokens. Groups components are reused, not copied. No API changes.

**Tech Stack:** SolidJS, TanStack Start (Cloudflare Workers), Tailwind v4 tokens from `design/tokens.json`, `motion/mini` via `lib/motion.ts`, vitest.

**Spec:** `docs/superpowers/specs/2026-10-22-boards-and-ask-aaru-design.md` (Part 1 Web), amended by the owner decisions below.

## Owner decisions (2026-10-23, supersede the spec's "Social tab")

- The Board lives **on Friends**: `/app/friends` opens on **Board**; **Lately** (today's Friends content: For you from friends, activity, leaderboard, Invite/requests/friends) is the second view of a `Board | Lately` segmented control. No nav rename, Groups untouched.
- Comments open on a **post page**, `/app/friends/posts/$postId`: the post, who upvoted, the thread (one level of replies), a reply box.
- The composer is an **inline box at the top** of Board that grows on focus. No floating button, no dialog.

## Global Constraints

- Worktree `/Users/fernandocorreiachill/Work/production/apps/aaru-wt-board002`, branch `feat/board-002-web`. Commands run in `aaru-client/`.
- Web uses only Aaru tokens (`bg-paper`, `bg-surface`, `text-ink`, `text-muted`, `accent`, `line`, `medallion`, `danger`, `font-display`, radii `rounded-card|panel|field`) and primitives from `src/components/ui`; motion only through `lib/motion.ts` and always still under reduced motion. No new UI libraries. Load the `frontend-design` and `emil-design-eng` skills before writing components (owner: no generic UI).

- Ratings are stored out of ten and shown as five stars with halves (`9` → ★★★★½), like the title page.
- Body limit 4000 characters; show the remaining count only under 200 left (reuse `remainingLabel` from `lib/groups/model.ts`).
- Spoilers: a `veiled` post or a veiled title shows `SpoilerVeil` until tapped; the author never sees a veil.
- `@aaru` is not offered in Board composers until BOARD-004 (the server records but does not answer). `@handle` suggestions offer the post author and your friends.
- Server functions follow `lib/groups/server.ts`: `createServerFn`, zod validators, `api(sessionToken())`, `check`/`checkEmpty` from `lib/groups/responses.ts` (or a shared copy if it is groups-private).
- Every new route gets a key in `size-budget.json` (measured + 3%); never commit `--update` output wholesale.
- Done means `npm run check && npm run lint && npm run typecheck && npm test && npm run build && npm run size` pass.

## Review Focus

1. **Empty Board:** no friends, or friends with no posts — Board shows the owl empty state with a line pointing to Invite (in Lately) and still offers the composer. Test the model's empty-state choice in Task 1; check the page renders it in Task 3.
2. **A comment page that comes back empty but has `next`:** the thread keeps loading (follows `next`), never shows "No comments" while `next` is set. Test in Task 1 (`shouldLoadMore`).
3. **Optimistic upvote that fails:** the count and ring roll back and a toast says why. Test the pure reducer in Task 1.
4. **Deleted comment with replies:** shows "Comment deleted" in muted text, no author, replies still under it. Test the threading in Task 1.
5. **A review of a title you already have:** the composer's preview says the rating changes and status stays; for a new title it names the status it lands on, and for a show it says "Watched, or Watching if it's still airing". Test `reviewEffect` in Task 1.

### Task 1: Board model (pure, tested)

**Files:**
- Create: `aaru-client/src/lib/board/model.ts`
- Test: `aaru-client/src/lib/board/model.test.ts`

**Interfaces (Produces):**
```ts
export type BoardPost = components['schemas']['BoardPost']
export type BoardComment = components['schemas']['BoardComment']
export type BoardSort = 'recent' | 'top'
export function starsLabel(rating: number): string                 // 9 → '★★★★½', 4 → '★★☆☆☆'
export function spoilerLabel(stamp: SpoilerStamp | undefined): string | null  // 'Spoilers up to S2 · E10' | 'Spoilers for the ending' | null
export function reviewEffect(hit: { title: string; type: MediaType; libraryItemId?: string }, rating?: number): string | null
export type Thread = { comment: BoardComment; replies: BoardComment[] }
export function threadComments(items: BoardComment[]): Thread[]     // top-level in order; replies under their replyTo in order; orphans (replyTo not in list) as top-level
export function mergeComments(current: BoardComment[], page: BoardComment[]): BoardComment[] // dedupe by id, keep order
export function shouldLoadMore(page: { items: unknown[]; next?: string | null }): boolean    // true whenever next is set, even with 0 items
export type UpvoteState = { upvotes: number; upvotedByMe: boolean }
export function toggleUpvote(s: UpvoteState): UpvoteState
export function boardEmpty(posts: BoardPost[], friendCount: number): 'no-friends' | 'quiet' | null
```
