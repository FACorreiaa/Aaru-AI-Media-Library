# Moving cdn.aaruapp.com to R2

*Written 2026-11-12. Status: not started, and not needed yet. R2 is enabled on the Cloudflare
account (owner, 2026-11-12); no bucket exists.*

Today `cdn.aaruapp.com` is a Worker with static assets and no code (`wrangler.jsonc` and
`README.md` beside this file). It serves one file, the 3D owl's model for the web (BRD-011). That
is enough for one file. This note says when it stops being enough, and how to move without
changing an address.

## When to move

Move when either of these becomes true. Until then, leave it.

1. **The 3D owl is a go and the other apps follow.** Then there are several mascots, several
   versions of each, and two formats per model. A Worker deploy replaces the whole file set every
   time, so one forgotten file in the local folder takes a live address away. A bucket takes one
   file at a time and keeps the rest.
2. **Mascot videos ship.** `~/Work/production/apps/MASCOT-ANIMATION-PLAN.md` §2.4 already names
   R2 for the clips. A Worker asset cannot be larger than 25 MB, and the clips, with their
   sources kept out of git, are the kind of media a bucket is for.

Not a reason to move: speed. Both are served from Cloudflare's edge with the same cache rules.

## What changes and what does not

| | Static Worker (today) | R2 bucket |
|---|---|---|
| Address | `cdn.aaruapp.com/aaru/owl3d/v1/owl.glb` | the same |
| Upload | the whole set, every deploy | one file at a time |
| Largest file | 25 MB | far beyond anything here |
| Headers | `_headers` file in the set | per file at upload, plus a CORS rule on the bucket |
| A file left out locally | disappears from the address | stays |
| Cost | none | none at this size: R2's free allowance is 10 GB stored, and it charges nothing for downloads |
| App config | `OWL_3D_MODEL_URL` | unchanged |

The rules in `README.md` stay as they are: a new cut is a new path, never an overwrite, and
nothing personal or secret goes there.

## Decisions to take first

- **One bucket or one per app.** Recommended: one bucket, a folder per app (`/aaru/…`,
  `/norviq/…`), as the mascot plan lays it out and as the owl's path already does. Each app's
  own `cdn.` host can be attached to the same bucket, so no app loads media from another app's
  domain.
- **Who uploads.** By hand from the owner's Mac is enough while cuts are rare. Do not add a CI
  upload before there is a second person or a weekly cut.
- **The token.** The aaruapp.com token in the Keychain (`cloudflare-api-token-aaru`) was refused
  by R2 on 2026-11-12. It needs "Workers R2 Storage: Edit" added, or a second token that holds
  only that.

## The move

Check each command against `npx wrangler r2 --help` first: the flags have changed between
wrangler versions.

1. **Create the bucket** (suggested name `mascots`):
   `npx wrangler r2 bucket create mascots`
2. **Upload every file the Worker serves today, at the same paths**, each with its type and the
   year-long cache:

   ```sh
   npx wrangler r2 object put mascots/aaru/owl3d/v1/owl.glb \
     --file docs/brand/out/cdn/aaru/owl3d/v1/owl.glb \
     --content-type model/gltf-binary \
     --cache-control "public, max-age=31536000, immutable" --remote
   ```

3. **Allow other sites to read it.** The web owl is fetched by script from `beta.aaruapp.com`,
   so the bucket needs a CORS rule that allows `GET` from any origin, which is what the Worker's
   `_headers` gives today.
4. **Check the bucket before switching**, through its temporary `r2.dev` address or a second
   host: the file's size, its `Content-Type`, its `Cache-Control`, and the CORS header.
5. **Switch the host.** `cdn.aaruapp.com` can belong to one thing at a time: remove it from the
   `aaru-cdn` Worker, then attach it to the bucket as a custom domain. For the minute in between
   the address answers nothing. That is safe here: the web owl keeps its still when the model
   does not load, and a browser that already has the file keeps it for a year.
6. **Check the live address** from a network that can reach it, then open
   `beta.aaruapp.com/sign-in` signed out and see the owl.
7. **Retire the Worker**: delete `aaru-cdn`, remove `wrangler.jsonc` here, and rewrite
   `README.md` for the bucket. Update the two lines that name the static Worker in
   `ARCHITECTURE.md` and `CLAUDE.md`, and the comment in `aaru-client/wrangler.jsonc`.

## Done when

- Every path the Worker served answers from the bucket with the same bytes and headers.
- No app's config changed.
- The `aaru-cdn` Worker is gone, and `README.md` describes one way to publish a file, not two.
