# Demo import data

Fictional files for filming imports (`../../rules/video-playbook.md`, shots B1–B3). Nobody's real
history. `letterboxd-demo.csv` is shaped like Letterboxd's `diary.csv`/`ratings.csv`
(`Date, Name, Year, Letterboxd URI, Rating`; URIs are placeholders). "Little Women" has no year on
purpose: it gives the match table one row to fix on camera (shot B2).
